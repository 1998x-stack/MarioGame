# MarioGame · Pygame 平台动作游戏

此仓库包含 Python/Pygame 实现的多关卡平台游戏代码、角色、敌人、金币、跳跃和背景素材。**这是上游源码项目，不是已经独立验证的在线试玩。**

## 本地运行

```bash
python -m pip install "pygame>=2.5,<3"
python main.py
```

使用左右方向键移动，**Space** 跳跃（双跳），吃金币得分；碰撞敌人失去生命。按 **R** 可重新开始第一关并重置分数和生命，**Esc/Q** 退出。

## 本轮工程修复

- 从仓库根目录解析资源路径，不依赖运行命令的工作目录。
- 没有音频设备或缺少可选音效时游戏不应中断。
- 加入游戏重开/退出路径、有限帧虚拟窗口冒烟和游戏场景测试。
- CI 使用虚拟 SDL 验证已有图像素材加载、等级初始化、重开与静音路径。

```bash
SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy python -m unittest discover -s tests -v
```
